## Sobre mim

Sou desenvolvedor focado em **backend com Rust**, criando APIs e serviços com ênfase em:

- performance e baixa latência;
- arquitetura limpa e escalável;
- segurança e previsibilidade operacional;
- código sustentável para evolução contínua.

Atualmente estou aprofundando soluções para produtos SaaS, APIs robustas e automações de engenharia.
